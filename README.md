# Alpine Book 📖🏔️

<div align="center">
  Um guia completo do Alpine Linux em <strong>Português Brasileiro</strong>, do básico ao avançado.
</div>

## ✨ Características

- 📚 63 lições em 14 módulos: apk, OpenRC, musl & BusyBox, redes, containers, servidores e segurança
- 🎯 Conteúdo prático com comandos reais, saídas de terminal e erros comuns resolvidos
- 🌙 Tema claro e escuro
- 📊 Progresso de estudo salvo no navegador

## 🚀 Stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/) + [Tailwind CSS](https://tailwindcss.com/)
- [wouter](https://github.com/molefrog/wouter) (rotas com hash, ideais para site estático)

## 🏃 Rodando localmente

```bash
pnpm install
pnpm dev
```

## 📦 Build

```bash
pnpm build   # saída em dist/
```
